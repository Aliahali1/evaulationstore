# مغامرة محققة المتجر الإلكتروني

موقع تعليمي عربي تفاعلي لاستمارة تقييم متجر إلكتروني لطالبات الصف الثالث المتوسط، بهوية بصرية مستوحاة من بوليفارد الرياض.

## محتويات الحزمة

- `index.html`: هيكل الموقع.
- `styles.css`: التصميم المتجاوب والألوان والمؤثرات.
- `app.js`: مراحل الاستمارة، المعايير الـ21، الحسابات، حفظ المسودة، والإرسال إلى Apps Script.
- `Code.gs`: الخادم الذي ينشئ جداول Google Sheets ويستقبل المشاركات ويتحقق من حالة الحفظ.
- `boulevard-hero.webp`: صورة بوليفارد الرياض المستخدمة في واجهة البداية.

## تشغيل الموقع محليًا

يمكن فتح `index.html` مباشرة لمعاينة واجهات الموقع، لكن الأفضل تشغيل مجلد المشروع من خادم محلي بسيط أثناء التطوير. الحفظ إلى Google Sheets لا يعمل حتى إعداد Apps Script ووضع عنوانه في `app.js`.

## مسار الطالبة وتقييم الأقران

تبدأ الطالبة باسمها وفصلها (ثالث 1 إلى ثالث 6) واسم المجموعة وأسماء زميلاتها، ثم تدخل بيانات المتجر، وتقيّم المحاور الخمسة (21 معيارًا)، وتحدد التوصية النهائية، ثم تقيم زميلاتها وفق خمسة معايير من 1 إلى 4. لا يسمح النموذج بتقييم الطالبة لنفسها، ويتطلب إكمال تقييم الزميلات قبل إرسال المشاركة.

نقاط الإنجاز من 100: 10 لبيانات المهمة، و15 لكل محور مكتمل (75)، و10 عند توثيق ثلاث ملاحظات أدلة على الأقل، و5 لإكمال تقييم الأقران. هذه النقاط تقيس تنفيذ المشروع ولا تقيس موثوقية المتجر.

## إعداد Google Sheets

1. سجلي الدخول إلى حساب Google الخاص بالمعلمة.
2. افتحي `script.google.com` وأنشئي مشروع Apps Script مستقلًا.
3. انسخي كامل محتوى `Code.gs` إلى ملف `Code.gs` في المشروع.
4. من قائمة الدوال اختاري `setupProject` ثم اضغطي Run ووافقي على الصلاحيات. سينشئ السكربت ملف Google Sheets خاصًا بحساب المعلمة، ويضيف أوراق البيانات المطلوبة. راجعي سجل التنفيذ للحصول على رابط الملف.
5. في الدالة `setClassAccessCode`، استبدلي `CHANGE-THIS-CLASS-CODE` برمز صف قوي وغير متداول، ثم شغلي الدالة مرة واحدة. لا تضعي هذا الرمز في ملفات GitHub أو في الكود الأمامي. زوّدي الطالبات به عبر قناة الصف المناسبة.
6. اختبري إعداد الرمز قبل النشر؛ لن يقبل الخادم الحفظ ما لم يتم تفعيل رمز الدخول.

## نشر Google Apps Script

1. من Apps Script اختاري Deploy ثم New deployment.
2. اختاري النوع Web app.
3. اجعلي التنفيذ باسم حساب المعلمة (Execute as: Me).
4. اختاري إعداد وصول يسمح لطالباتك بالوصول وفق سياسة المدرسة وحسابات Google المتاحة لديهن. قد تختلف الخيارات المتاحة بحسب إعدادات Google Workspace وسياسات المسؤول.
5. انشري التطبيق وانسخي رابط Web App الذي ينتهي غالبًا بـ `/exec`.
6. لا تشاركي ملف Google Sheets نفسه مع الطالبات. يحتفظ حساب المعلمة بملكية الملف وصلاحية الاطلاع على البيانات.

**تنبيه خصوصية:** واجهة GitHub Pages عامة بطبيعتها، ورابط Apps Script سيكون نقطة استقبال. لا تضعي بيانات حساسة في الاستمارة. استخدمي رمز دخول الصف (إلزامي في هذا الإصدار)، وشاركي الرابط والرمز مع الطالبات عبر قناة المدرسة فقط. إذا كانت سياسة المدرسة لا تسمح بنقطة استقبال عامة، فلا تنشري هذا التكامل قبل مراجعة مسؤول Google Workspace/تقنية المعلومات، واستخدمي بديلًا معتمدًا مثل نموذج مؤسسي يتطلب تسجيل الدخول.

## ربط الموقع بـ Apps Script

1. افتحي `app.js`.
2. ابحثي عن:

   ```js
   APPS_SCRIPT_URL: ""
   ```

3. ضعي رابط Apps Script المنشور بين علامتي الاقتباس، مثل:

   ```js
   APPS_SCRIPT_URL: "https://script.google.com/macros/s/REPLACE_WITH_DEPLOYMENT_ID/exec"
   ```

4. احفظي الملف.
5. اختبري المشاركة من صفحة GitHub Pages المنشورة، وليس من معاينة المحرر فقط.

يستخدم الموقع طلب POST بصيغة نموذجية ويراقب حالة الحفظ من خلال طلب JSONP يحمل معرف مشاركة عشوائيًا. لا يعرض الخادم أي أسماء أو درجات عند فحص حالة الحفظ؛ بل يعيد فقط قيمة `found: true/false` لمعرف المشاركة المرسل.

## نشر الموقع على GitHub Pages

1. أنشئي مستودعًا جديدًا في GitHub أو استخدمي مستودعًا مناسبًا.
2. ارفعي جميع الملفات كما هي، مع بقاء `index.html` في جذر النشر.
3. من إعدادات المستودع افتحي Pages.
4. اختاري فرع النشر والمجلد الجذر `/` وفق واجهة GitHub الحالية، ثم احفظي.
5. انتظري اكتمال النشر من GitHub Pages، ثم افتحي الرابط واختبريه على الحاسب والجوال.

## اختبار قبول المشاركة

1. أدخلي اسمًا تجريبيًا غير حقيقي وفصلًا من القائمة.
2. أدخلي متجرًا تجريبيًا ورابطًا عامًا.
3. اختاري درجة لكل معيار من المعايير الـ21، بما في ذلك تجربة اختيار «غير متاح» في بعض المعايير.
4. اختاري توصية نهائية وأرسلي المشاركة باستخدام رمز الصف الصحيح.
5. تأكدي من ظهور رسالة النجاح بعد التحقق من معرف المشاركة.
6. افتحي Google Sheets بحساب المعلمة وتأكدي من وجود السجل في `Student_Records` و`Store_Info` و`Criteria_Scores` و`Assessment_Summary` و`Peer_Assessment` و`Achievements`.
7. أعيدي الاختبار برمز خاطئ، ويجب أن يفشل الحفظ مع بقاء الإجابات على الشاشة.
8. احذفي سجلات الاختبار التجريبية قبل بدء الاستخدام مع الطالبات.

## منطق احتساب الدرجات

- 21 معيارًا × 5 درجات = 105 درجات كحد أعلى.
- 5 = متحقق بوضوح.
- 3 = متحقق جزئيًا.
- 0 = غير متحقق.
- غير متاح للتحقق: يستبعد من المقام.
- لا تظهر نتيجة نهائية قابلة للإرسال حتى يتم اختيار حالة لكل معيار، ويجب أن يوجد معيار واحد على الأقل قابل للتقييم.

## ملاحظات تقنية

- المسودة تحفظ مؤقتًا في `localStorage` على جهاز الطالبة لمساعدتها على استعادة العمل؛ ليست هذه قاعدة البيانات النهائية.
- السجل النهائي لا يُعد محفوظًا إلا بعد أن يؤكد Apps Script وجود معرف المشاركة في ورقة الملخص.
- الأوراق تبقى خاصة بحساب المعلمة ما لم تشاركيها بنفسك.
- لوحة المعلمة: زر «دخول المعلمة» في رأس الموقع وتذييله يفتح `‎/exec?page=teacher` ويطلب رمز المعلمة (يُضبط بـ `setTeacherCode`).
